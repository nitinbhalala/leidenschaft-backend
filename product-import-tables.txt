PRODUCT IMPORT — TABLE CHANGES SUMMARY
(created by: POST /api/admin/products/import -> ProductImportController)

===========================================
TABLES TRUNCATED (all old data deleted)
===========================================
- products
- product_images
- product_inventories
- product_reviews
- order_items
- orders
- payments
- carts
- wishlists
- scene_pins

Old image files under storage/app/public/products were also deleted from disk.

===========================================
COLUMNS CLEARED (not truncated, just set to NULL)
===========================================
- home_page_settings.section_2_product_ids
- home_page_settings.section_2_product_position

===========================================
TABLES DATA ADDED TO (from the imported CSV/Excel file)
===========================================
- products            -> 1 row per active-status product in the file
- product_images       -> downloaded product images (from Image Src column)
- product_inventories   -> 1 inventory row per imported product (stock + status)
- categories           -> new rows only added here if a product's Type/Tag
                          did not match any existing category name
                          (existing matching categories are reused, not duplicated)

===========================================
TABLES NOT TOUCHED (kept as-is)
===========================================
- customers
- everything else in the database

===========================================
NOTES
===========================================
- Only rows with Status = "active" in the file are imported. Draft/other
  status rows are skipped and counted in the "skipped_draft" summary.
- Matching key for existing SKU/ref: "Variant SKU" column in the file
  -> products.sku column in the database.
- category_id is matched against Type/Tags first; if nothing matches an
  existing top-level category, a new category is auto-created.
- sub_category_id is only set if a Tag matches an existing child category
  of the chosen category; otherwise it is left empty.
- IMPORTANT: every Import click now also permanently deletes ALL order and
  payment history (not just their product references), since orders and
  payments are fully truncated along with the product tables.
